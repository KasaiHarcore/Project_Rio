# Webpage building block

***Technical Stack***
- Next.js: Constructor (The frame that builds the house)
- React: Manager (The logic that controls the rooms)
- CSS / Tailwind: Designer (The style and layout)
- Vercel AI SDK: Courier (Streams data from the brain to the screen)
- Shadcn UI: Carpenter (Crafts the high-end buttons and panels)
- Framer Motion: Choreographer (Animates the "thinking" and transitions)
- React Markdown: Translator (Turns raw AI text into beautiful articles)
- Shiki: Illuminator (Colors and highlights the agent's code)
- Lucide: Signage (Provides the professional icons)
- Zustand: Secretary (Remembers the global state of the app)
